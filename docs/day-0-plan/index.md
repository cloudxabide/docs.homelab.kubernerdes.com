# Day 0 - Plan

Planning and architecture decisions made before building anything.

- Decide on domain and IP scheme
- Choose deployment mode (`community`, `prime`, or `enclave`) per environment
- For `enclave`: plan the air-gapped registry/mirroring architecture (Harbor + image/chart mirroring) — see [Air-gapped Kubernetes & Containers Quick Guide](https://github.com/cloudxabide/homelab.kubernerdes.com/blob/main/DeepDive/Airgap_Overview.md)

See the source repo's [PLAN.md](https://github.com/cloudxabide/homelab.kubernerdes.com/blob/main/PLAN.md) and [Hardware.md](https://github.com/cloudxabide/homelab.kubernerdes.com/blob/main/Hardware.md) for the current inventory, IP assignments, and network layout. For product background and reference material, see [Deep Dives](/docs/deep-dives).
